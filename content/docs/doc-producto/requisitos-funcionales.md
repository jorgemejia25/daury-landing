| ID | Requerimiento | Descripción |
|---|---|---|
| FR-01 | Gestión de autenticación | El sistema debe permitir inicio de sesión, registro y recuperación de credenciales. |
| FR-02 | Tutorial de bienvenida | El sistema debe mostrar un tutorial inicial con slides y captura de nombres de la persona cuidada y de sus cuidadores. |
| FR-03 | Reinicio del tutorial | El sistema debe permitir reiniciar el tutorial de bienvenida desde ajustes. |
| FR-04 | Configuración inicial de accesibilidad | El sistema debe permitir configurar voz y tamaño de texto grande durante el onboarding inicial. |
| FR-05 | Modo emergencia | El sistema debe ofrecer llamadas rápidas y acceso a una ficha médica para personal médico. |
| FR-06 | Contactos de emergencia | El sistema debe permitir registrar, editar y consultar contactos de emergencia. |
| FR-07 | Ficha de datos generales | El sistema debe permitir mantener una ficha con datos generales y condición de la persona cuidada. |
| FR-08 | Lista de medicación activa | El sistema debe permitir registrar y consultar la medicación activa. |
| FR-09 | Miembros del círculo de cuidado | El sistema debe permitir gestionar miembros del círculo de cuidado y sus roles. |
| FR-10 | Invitación de miembros | El sistema debe permitir invitar nuevos miembros mediante enlace o código. |
| FR-11 | Recordatorios por actividad | El sistema debe generar recordatorios activos asociados a cada actividad. |
| FR-12 | Alta de actividad manual | El sistema debe permitir crear actividades manualmente con plantilla, hora y frecuencia. |
| FR-13 | Alta de actividad por IA | El sistema debe permitir crear actividades a partir de una foto de receta y lectura automática con confirmación posterior. |
| FR-14 | Vista diaria de actividades | El sistema debe mostrar las actividades del día con su estado de pendiente o completada y el progreso general. |
| FR-15 | Registro de observaciones | El sistema debe permitir registrar observaciones asociadas a las actividades. |
| FR-16 | Registro de ánimo | El sistema debe permitir registrar el ánimo de la persona cuidada. |
| FR-17 | Registro de incidentes | El sistema debe permitir registrar incidentes ocurridos durante el cuidado. |
| FR-18 | Adherencia semanal | El sistema debe mostrar la adherencia con detalle por día, semana y mes. |
| FR-19 | Guardado local | El sistema debe guardar la información localmente para permitir su uso sin conexión. |
| FR-20 | Sincronización al reconectar | El sistema debe sincronizar automáticamente los datos pendientes cuando se recupere la conexión. |
| FR-21 | Compartir historial con el doctor | El sistema debe permitir compartir el historial con el doctor en formato PIDIEF o equivalente definido por el negocio. |
| FR-22 | Alerta automática por anomalías | El sistema debe detectar anomalías mediante IA y emitir alertas automáticas cuando corresponda. |
