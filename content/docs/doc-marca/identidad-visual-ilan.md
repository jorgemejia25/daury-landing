1. ESTILO DE DISEÑO

El enfoque ideal es el Soft Friendly Flat o Estilo de Ilustración Corporativa Amigable: 

Bordes muy redondeados: Transmiten ternura, cuidado y seguridad.



Altísimo contraste: Botones grandes, planos, con bordes definidos para que se sepa exactamente dónde presionar.



Claridad cognitiva: Los elementos visuales debe ser tan obvios que el cuidador no tiene que adivinar qué hace un botón.

1. TIPOGRAFÍA La tipografía debe ser extremadamente legible, limpia y con un toque redondo para parecer más natural. 

Tipografía Principal (Títulos e Instrucciones): Bricolage Grotesque



Tipografía de Soporte (Texto/Datos/Números): Geist.

Regla de oro para Daury: El tamaño de fuente por defecto debe ser grande y con mucho espacio entre líneas.

4. ÍCONOS  Opción 1: Phosphor Icons (Estilo Duotone y Trazo Amigable) 

Ventaja Visual: Permite el estilo Duotone (dos colores). Se puede rellenar el fondo del ícono con el Azul Claro (#add5fa) y dejar las líneas en Gris Oscuro (#1f1f1f). Es la opción que se ve más tierna, personalizada y alineada a la paleta de Daury.



Código de instalación: npm install phosphor-react (o phosphor-react-native)



Línea de importación: import { Pill, Drop, Megaphone } from 'phosphor-react';

 Opción 2: Lucide Icons (Ligereza y Alta Legibilidad) 

Ventaja Visual: Los vectores son súper limpios y ligeros para el rendimiento de la app. Para adaptarlo al estilo Soft Friendly del proyecto, solo se debe engrosar el trazo modificando la propiedad a strokeWidth={3}, lo que hace que el ícono sea ultra reconocible para baja alfabetización.



Código de instalación: npm install lucide-react



Línea de importación: import { Pill, Droplet, Megaphone } from 'lucide-react';
