## Un lugar para lo que sabemos

Esta wiki reúne la información de Daury para que sea fácil encontrarla y mantenerla al día. Comienza con las guías de producto, identidad visual y tecnología.

- [Sobre Daury](/wiki/producto): el propósito del producto y las personas para quienes lo construimos.
- [Identidad y diseño](/wiki/diseno): colores, tipografía y criterios para diseñar con la marca.
- [Tecnología](/wiki/tecnologia): cómo está organizado este espacio.
- [Cómo actualizar la wiki](/wiki/guia): el flujo para mantener los documentos.

## Una base que seguirá creciendo

Cada documento debe tener un propósito claro, enlaces a sus referencias y contexto suficiente para entenderlo sin buscar en una conversación anterior.

Las decisiones, procesos y recursos del proyecto se incorporarán aquí a medida que se documenten.
